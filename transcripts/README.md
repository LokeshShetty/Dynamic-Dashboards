# Session transcripts

AI tools were used to build this project: the work was done in a series of sessions with an
assistant, one per phase, each ending with a green `npm run check` and a commit.

The commit history is the honest summary of what happened: nine feature phases, several
reversals, and the reasons for both. `DESIGN.md` records the decisions, including the ones that
were later undone and why.

**Add the exported session transcripts to this folder before sharing the repository.** They are
deliberately not committed automatically: a transcript is a verbatim record of a working session
and should be read once before it is published.
